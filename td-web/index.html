Where this data comes from

This site ships with data/trade-data.json: a compact snapshot of systems, stations and commodity markets. A scheduled GitHub Actions workflow (.github/workflows/update-data.yml) rebuilds that file on a timer and commits it back to the repo, so the live site refreshes itself without anyone running anything locally. It is not a live feed — a static site on GitHub Pages can't hold a persistent connection — but it's as close to live as a static page gets, on whatever schedule you set the workflow to.

The route optimizer itself runs entirely in your browser: it downloads the current trade-data.json once, then plans routes locally with no server round-trip.

Unofficial fan tool inspired by Trade Dangerous. Not affiliated with Frontier Developments.
